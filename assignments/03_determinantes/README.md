# Assignment 03 — Determinants and Invertibility

## Objective
Implement determinant methods, analyze invertibility, and compute inverses in both Python and JavaScript.

## Tasks
1. Implement `det_2x2(A)` and `det_3x3_sarrus(A)`; test on invertible and singular matrices.
2. Implement `det_gauss(A)` returning determinant and elimination steps; test on 4x4.
3. Verify determinant properties: product rule, transpose, scalar multiple, row swap sign flip, row-add invariance.
4. Implement `eh_invertivel(A)` and test on invertible, singular, and ill-conditioned matrices with condition numbers.
5. Implement `inversa_gauss_jordan(A)` and verify A * A^-1 = I for 3x3 and 4x4.
6. Visualize a 2x2 matrix transforming the unit square and show |det(A)| in the title.
7. Write `reflexao.md` (200–300 words) on geometric meaning and non-invertibility when det(A)=0.
