# Assignment 01 — Matrices: Construction and Classification

## Objective
Understand the structure of special matrix types, access elements programmatically, and build reusable classification functions in both Python and JavaScript.

## Tasks
1. Create a 3x4 zero matrix, 4x4 identity matrix, 3x3 diagonal with [2, 5, -1], upper and lower triangular 3x3 matrices, and a symmetric matrix M + M^T.
2. For each matrix from Task 1, print dimensions, the element a_2,3 (0-based indexing), and verify the value makes sense.
3. Implement `classificar_matriz(A)` returning labels from: `square`, `rectangular`, `zero`, `identity`, `diagonal`, `symmetric`, `upper_triangular`, `lower_triangular`.
4. Demonstrate incompatible addition and multiplication errors and print the error messages.
5. Write `reflexao.md` (150–250 words) explaining why the identity matrix satisfies multiple classifications and note Python vs JavaScript API differences.
