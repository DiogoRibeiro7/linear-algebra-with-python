# Assignment 1 — Matrices: Construction and Classification

## Objective
Understand special matrix types, access elements, and classify matrices programmatically.

## How to run
```bash
poetry run python assignments/01_matrizes_tipos/matrizes_tipos.py
```

## Skills
- Create special matrices (zero, identity, diagonal, triangular, symmetric)
- Access matrix elements and dimensions
- Classify matrices using reusable functions
- Handle dimension mismatch errors
