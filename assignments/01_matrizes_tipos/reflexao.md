# Reflection — Assignment 1

The identity matrix has 1s on the main diagonal and 0s everywhere else. That structure means it is diagonal by definition, and any diagonal matrix is also symmetric (because it equals its transpose). It is also both upper and lower triangular, since there are no nonzero entries above or below the diagonal.

In set terms, diagonal matrices are a subset of both symmetric and triangular matrices. The identity matrix is a particularly strict diagonal matrix (all diagonal entries are 1), so it lies at the intersection of several categories at once. That is why it appears in multiple classifications simultaneously.

These structural properties are tied to algebraic behavior: for any compatible matrix A, we have AI = IA = A, and det(I) = 1. The identity matrix is the neutral element of matrix multiplication, which makes it a central example in linear algebra.
