# Assignment 02 — Matrix Operations and Property Verification

## Objective
Practice matrix arithmetic and verify core algebraic properties in Python and JavaScript.

## Tasks
1. Define two 2x3 matrices A and B. Compute A+B, A-B, and 3A. Verify dimensions.
2. Define a 3x2 matrix C. Compute AC and CA, and explain the dimensional difference.
3. For 2x2 matrices P and Q, compute PQ, QP, and the commutator [P,Q] = PQ - QP. Verify identity behavior.
4. Verify transpose properties: (A^T)^T = A, (A+B)^T = A^T + B^T, (AC)^T = C^T A^T.
5. Build a random 3x3 M, set S = M + M^T, verify symmetry, and show Ax equals the linear combination of A's columns.
6. Write `reflexao.md` (150–250 words) about non-commutativity and language differences.
