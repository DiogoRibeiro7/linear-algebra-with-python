# Reflexão - Assignment 03

Neste trabalho foi possível aprender a calcular determinantes de matrizes de forma manual e com ajuda do NumPy. Também foi interessante perceber como o método de Gauss pode ser usado para calcular o determinante de uma matriz.

Além disso, foi calculada a inversa de uma matriz e verificado que o produto da matriz pela sua inversa resulta na matriz identidade.
Em Python, com NumPy, estas operações são simples de realizar. Em JavaScript, com math.js, algumas operações podem ser menos diretas.

No geral, Python facilitou bastante este trabalho.
