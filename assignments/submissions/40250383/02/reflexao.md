# Reflexão - Assignment 02

Neste trabalho foi possível perceber que a multiplicação de matrizes não é comutativa, ou seja, A·B não é igual a B·A na maioria dos casos. Também foi possível verificar propriedades da transposta, como (Aᵀ)ᵀ = A e (A·C)ᵀ = CᵀAᵀ.

Além disso, foi interessante ver que o produto Ax pode ser interpretado como uma combinação linear das colunas da matriz A.

Em Python, com NumPy, estas operações são simples de fazer. Em JavaScript, com math.js, algumas operações podem ser menos diretas.

No geral, Python facilitou bastante este trabalho.
