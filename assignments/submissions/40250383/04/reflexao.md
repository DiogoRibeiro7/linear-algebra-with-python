# Reflexão - Assignment 04

Neste trabalho foi possível resolver sistemas lineares usando Python e NumPy. Também foi interessante perceber como funciona o método de Gauss-Jordan para transformar matrizes e encontrar soluções.

Além disso, foi possível observar a diferença entre sistemas com solução única, sistemas impossíveis e sistemas com infinitas soluções.

Em Python, com NumPy, estas operações são simples e rápidas de fazer. Em JavaScript, com math.js, algumas operações podem ser menos diretas.
No geral, Python facilitou bastante este trabalho.
