# Reflexão - Assignment 01

A matriz identidade pertence a vários tipos de matrizes ao mesmo tempo. É diagonal porque só tem valores na diagonal principal. Também é simétrica, porque é igual à sua transposta. Além disso, é triangular superior e inferior, pois não tem valores fora da diagonal que sejam diferentes de zero. Por isso, podemos dizer que pertence a vários conjuntos ao mesmo tempo.

Em Python, usar o NumPy facilita bastante o trabalho com matrizes, porque já tem funções prontas. Em JavaScript, com math.js, algumas coisas são menos diretas. No geral, achei Python mais fácil de usar para este tipo de exercícios.
