# Assignment 01: Matrizes: Construção e Classificação

# T1 - Construção de Matrizes
Foi implementado a criação de matrizes específicas, incluindo:
- matrizes nulas
- identidades
- diagonais
- triangulares (superior e inferior)
- matriz simétrica gerada a partir da transposição

# T2 - Dados de matrizes
Implementação de visualização e acesso a elementos específicos:
- dimensões de cada matriz
- aceder a elementos específicos

# T3 - Classificação de matrizes
Há uma função personalizada capaz de analisar as propriedades de uma matriz e devolver a sua classificação correta.

# T4 - Gestão de Erros
Foram implementados blocos try/except para detetar e explicar erros comuns, como a tentativa de somar ou multiplicar matrizes com dimensões incompatíveis.
