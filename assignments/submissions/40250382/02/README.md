# Assignment 02 - Matrix Operations and Property Verification

## Objetivo
Este projeto realiza operações fundamentais de álgebra linear (soma, subtração, multiplicação escalar e de matrizes) e verifica propriedades como a não-comutatividade e identidades da transposta utilizando JavaScript e a biblioteca Math.js.

## Estrutura do Projeto
- `javascript/operacoes_matrizes.js`: Lógica principal das tarefas T1 a T5.
- `javascript/operacoes_matrizes.html`: Interface para execução no browser.
- `reflexao.md`: Reflexão sobre o significado da não-comutatividade.

## Como Executar
1. Certifica-te de que os ficheiros `.js` e `.html` estão na mesma pasta.
2. Abre o ficheiro `javascript/operacoes_matrizes.html` em qualquer navegador moderno.
3. Abre o Console do Desenvolvedor (**F12** ou **Ctrl+Shift+I**) para visualizar os logs detalhados de cada tarefa.
