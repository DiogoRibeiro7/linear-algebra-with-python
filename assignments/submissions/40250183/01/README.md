# Submissions

This folder is for student uploads.
See the full assignment specification at `assignments/ASSIGNMENTS.tex`.

## Folder naming

Each student must create a folder using the pattern:

```
40XXXXXX
```

Where `XXXXXX` are exactly six digits (e.g., `40250001`, `40260123`).

## Required files inside each student folder

- `README.md`
- `.gitkeep`
- `SUBMISSION_GUIDE.md`
- `01/` through `07/` (one folder per assignment)

Each assignment folder must include:

- `README.md`
- `python/` (your Python deliverables)
- `javascript/` (your JavaScript deliverables)
- `reflexao.md` (shared reflection)

Use the template in `assignments/submissions/40XXXXXX` as a starting point.
