# Reflexão – Assignment 02

Neste assignment consegui perceber melhor como funcionam as operações entre matrizes e como elas são diferentes das operações normais com números.

A parte mais interessante foi ver que a multiplicação de matrizes não é comutativa, ou seja, normalmente AB é diferente de BA. Isto ajudou-me a perceber que a ordem das operações é importante quando trabalhamos com matrizes.

Também achei útil verificar as propriedades da transposta, porque deu para confirmar com código regras que aprendemos nas aulas, como:

* (Aᵀ)ᵀ = A
* (A + B)ᵀ = Aᵀ + Bᵀ
* (AB)ᵀ = BᵀAᵀ

Outra parte importante foi perceber que o produto Ax pode ser visto como uma combinação linear das colunas da matriz A. Isso ajudou-me a compreender melhor a relação entre matrizes e sistemas lineares.

Tal como no assignment anterior, achei mais fácil utilizar Python do que JavaScript, principalmente por causa do NumPy. As funções são simples de usar e o operador `@` torna a multiplicação de matrizes muito mais fácil de escrever e entender.
