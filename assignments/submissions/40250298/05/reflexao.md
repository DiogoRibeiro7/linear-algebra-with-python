# Reflexão – Assignment 05

Neste trabalho consegui perceber melhor as diferenças entre vários métodos de resolução de sistemas de equações lineares.

No início achei a Regra de Cramer simples de implementar, mas rapidamente percebi que não é eficiente quando os sistemas começam a crescer, devido ao cálculo de determinantes. Isso ajudou-me a perceber porque é que este método não é usado em problemas grandes.

A decomposição LU foi a parte mais interessante do trabalho, porque permitiu perceber como uma matriz pode ser dividida em fatores mais simples. Também achei útil perceber que, depois de feita a decomposição, é possível resolver vários sistemas com diferentes vetores b sem repetir todo o processo, o que torna o método muito mais eficiente.

Outra coisa importante foi a comparação de tempos entre os métodos. Foi aqui que percebi claramente a diferença de eficiência entre Cramer, Gauss e LU, especialmente quando o tamanho das matrizes aumenta.

No geral, este trabalho ajudou-me a consolidar conceitos de álgebra linear e também a melhorar a minha capacidade de implementar algoritmos em Python. Sinto-me mais confortável com estes métodos e consigo agora perceber melhor quando cada um deve ser utilizado.
