# Assignment 07 — Surfaces of Revolution

## Objective
Generate and visualize surfaces of revolution, analyze cross-sections, and compare generating curves.

## Tasks
1. Implement `superficie_cilindro`, `superficie_cone`, and `superficie_esfera`; visualize each.
2. Create a summary table for standard surfaces, generating curves, axes, and equations.
3. Visualize cross-sections of a sphere of radius 2 at multiple z values.
4. Implement `superficie_revolucao(curva, eixo, t_range, n)` and test with a wavy vase and paraboloid.
5. Create a gallery figure with cylinder, cone, sphere, wavy vase, paraboloid, and hyperboloid.
6. Write `reflexao.md` (200–300 words) on how curves and axes define surfaces.
