# Assignment 06 — Analytic Geometry: Lines and Planes

## Objective
Classify relative positions of lines and planes, compute intersections, and visualize 2D/3D geometry.

## Tasks
1. Implement `posicao_relativa_retas_2d` for intersecting, parallel, and coincident lines; visualize all cases.
2. Extend to 3D with intersecting, parallel, coincident, and skew lines; visualize in a 2x2 grid.
3. Implement `plano_cartesiano_para_parametrico(a, b, c, d)` and test on two planes.
4. Implement `posicao_relativa_planos` and test on three plane pairs.
5. Implement `intersecao_reta_plano` and test intersecting, parallel, and contained cases.
6. Demonstrate dot product tests for parallelism and perpendicularity.
7. Create a comprehensive 3D visualization with plane, intersecting line, parallel line, normal, and intersection.
8. Write `reflexao.md` (200–300 words) on direction/normal vectors and relative positions.
