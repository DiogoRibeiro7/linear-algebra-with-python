\section{General Instructions}

\subsection{Overview}

This document contains the graded submission specification for Assignments A01 through A06 of the Linear Algebra and Analytic Geometry course. These assignments are released every two weeks and must be submitted via Pull Request to the course GitHub repository before the stated deadline. Assignment A07 remains in the repository as separate teaching material and is intentionally outside the graded submission-control workflow.

\begin{warnbox}
  \textbf{Entrega em uma linguagem.} Cada assignment pode ser realizado em Python \textbf{ou} JavaScript. Deve ser entregue apenas \textbf{uma} implementação (à escolha do estudante), e ela deve produzir os resultados pedidos.
\end{warnbox}

\subsection{Submission Procedure}

\begin{enumerate}[leftmargin=*]
  \item You will be added as a \textbf{collaborator} to the course repository at \url{https://github.com/diogoribeiro7/linear-algebra-with-python}. Accept the invitation sent to your GitHub account.
  \item Clone the repository to your local machine.
  \item Inside \texttt{assignments/submissions/}, create a folder named with your student number (e.g.,~\texttt{40250001}).
  \item For each assignment, create a subfolder (\texttt{01/}, \texttt{02/}, \ldots) containing \textbf{either} the Python \textbf{or} the JavaScript implementation.
  \item Create a \textbf{branch} named with your student number and assignment (e.g.,~\texttt{40250001-A01}).
  \item Commit your changes, push, and open a \textbf{Pull Request} against the \texttt{develop} branch with a clear title (e.g.,~\emph{Submission 40250001 --- A01}).
\end{enumerate}

\subsection{Technical Requirements}

\subsubsection{Python Track}

All Python code must run with \textbf{Python~3.11+} using the project dependencies managed by Poetry. Install the project environment from \texttt{packages/python} with \texttt{poetry install}. Use the utility modules in \texttt{packages/python/src/linalg\_utils/} where appropriate --- you are expected to import and use these functions rather than reimplementing them from scratch (unless the task explicitly asks for an implementation).

\begin{pythonbox}[Key Python Libraries]
  \texttt{numpy} --- array operations and linear algebra\\
  \texttt{scipy} --- LU decomposition, advanced routines\\
  \texttt{matplotlib} --- 2D and 3D visualization\\
  \texttt{sympy} --- symbolic computation (optional)
\end{pythonbox}

\subsubsection{JavaScript Track}

All JavaScript code must run with \textbf{Node.js~20+} or in a modern browser. The project includes a \texttt{package.json} in \texttt{packages/js}. Install the JavaScript dependencies from \texttt{packages/js} with \texttt{yarn install}.

\begin{jsbox}[Key JavaScript Libraries]
  \texttt{mathjs} --- matrix operations, linear algebra, and symbolic math\\
  \texttt{plotly.js} --- interactive 2D and 3D visualization (browser)\\
  \texttt{d3.js} --- data-driven visualization (browser)\\
  \texttt{chart.js} --- charting (optional, for simpler plots)\\
  \texttt{numeric.js} --- numerical methods (optional alternative to mathjs)
\end{jsbox}

\section{Assignment 01 --- Matrices: Construction and Classification}

\assignmentmeta{Matrices}{Introductory}{2026-04-08}{01}

\subsection{Objective}

Understand the structure of special matrix types, access individual elements programmatically, and build reusable classification functions using NumPy (Python) and math.js (JavaScript).

\subsection{Context}

Matrices are the foundational data structure in linear algebra. Before performing operations or solving systems, you must be comfortable creating, inspecting, and classifying matrices. This assignment ensures you have a solid practical foundation in the chosen language.

\subsection{Learning Outcomes}

\begin{itemize}[leftmargin=*]
  \item Create special matrices (zero, identity, diagonal, triangular, symmetric).
  \item Access elements by index and inspect dimensions.
  \item Write reusable functions for matrix classification in Python or JavaScript.
  \item Handle dimension mismatch errors gracefully in the chosen language.
\end{itemize}

\section{Assignment 02 --- Matrix Operations and Property Verification}

\assignmentmeta{Operations, Transpose}{Introductory}{2026-04-22}{02}

\subsection{Objective}

Practice matrix arithmetic operations and computationally verify fundamental algebraic properties such as non-commutativity, transpose identities, and the linear combination interpretation of matrix-vector products --- in Python or JavaScript.

\subsection{Context}

Matrix algebra differs from scalar algebra in important ways. Multiplication is generally not commutative, and the transpose operation interacts with products in a specific order-reversing fashion. Verifying these properties computationally in two different languages builds deep intuition and cross-platform fluency.

\subsection{Learning Outcomes}

\begin{itemize}[leftmargin=*]
  \item Perform matrix addition, subtraction, and scalar multiplication.
  \item Compute matrix products respecting dimension rules.
  \item Verify non-commutativity and compute commutators.
  \item Prove transpose properties computationally.
  \item Interpret $Ax$ as a linear combination of the columns of $A$.
\end{itemize}

\subsection{Tasks}

\renewcommand{\arraystretch}{1.3}
\begin{tabularx}{\textwidth}{
  >{\centering\bfseries\cellcolor{lightblue}}p{0.8cm}
  X
  p{3.5cm}
}
\toprule
\rowcolor{ippblue}
\textcolor{white}{\#} & \textcolor{white}{\textbf{Task Description}} & \textcolor{white}{\textbf{Expected Output}} \\
\midrule
T1 & \bothlabel\ Define two $2 \times 3$ matrices $A$ and $B$. Compute and print $A + B$, $A - B$, and $3A$. Verify that the sum preserves dimensions using an assertion. & Computed results with verification \\
\rowcolor{lightgray}
T2 & \bothlabel\ Define a $3 \times 2$ matrix $C$. Compute $AC$ ($2 \times 3$ times $3 \times 2$) and $CA$ ($3 \times 2$ times $2 \times 3$). Print both results and explain why they have different dimensions and are not equal. & Products with dimensional analysis \\
T3 & \bothlabel\ For two $2 \times 2$ matrices $P$ and $Q$, compute $PQ$, $QP$, and the commutator $[P,Q] = PQ - QP$. Show that $PQ \neq QP$ in general, but that $PI = IP = P$ for the identity matrix. & Commutator and identity verification \\
\rowcolor{lightgray}
T4 & \bothlabel\ Verify the three transpose properties computationally: (a)~$(A^\top)^\top = A$; (b)~$(A+B)^\top = A^\top + B^\top$; (c)~$(AC)^\top = C^\top A^\top$. Use approximate comparison for each. & Boolean verification of each property \\
T5 & \bothlabel\ Generate a random $3 \times 3$ matrix $M$ and construct $S = M + M^\top$. Verify that $S$ is symmetric. Then define a $3 \times 3$ system matrix and a vector $\mathbf{x}$, compute $A\mathbf{x}$, and show that $A\mathbf{x}$ equals the linear combination $x_1 \mathbf{a}_1 + x_2 \mathbf{a}_2 + x_3 \mathbf{a}_3$ where $\mathbf{a}_i$ are the columns of $A$. & Symmetry proof and linear combination \\
\rowcolor{lightgray}
T6 & Write a \texttt{reflexao.md} (150--250 words) explaining the geometric or algebraic significance of non-commutativity in matrix multiplication. Compare how the two languages express these operations. & \texttt{reflexao.md} file \\
\bottomrule
\end{tabularx}

\begin{hintbox}
