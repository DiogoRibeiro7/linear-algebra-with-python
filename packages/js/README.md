# linalg-utils (TypeScript)

TypeScript port of `linalg_utils` for the Linear Algebra course.

## Prerequisites
- Node.js 20+
- Yarn (Berry)

## Libraries
This package includes the JavaScript libraries referenced in the assignment spec:
`mathjs`, `plotly.js-dist-min`, `d3`, `chart.js`, and `numeric`.

## Install
```bash
yarn install
```

## Test
```bash
yarn test
```

## Build
```bash
yarn build
```
